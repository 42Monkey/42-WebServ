How to Use:

1. Start your WebServ: ./webserv

2. Connect (3 ways):

  • Auto Discover: Click "Auto Discover" to scan ports 8080, 9081, 9091
  • Manual: Enter host/port and click Connect
  • URL Params: ?host=localhost&port=8080

3. CGI Scripts Manager:

  • Enter script name in the CGI input field (e.g., script.py, test.cgi)
  • Choose method: GET (retrieve), POST (send data), or DELETE (remove)
  • Click the method button to execute the CGI script
  • Scripts are executed at /cgi-bin/scriptname

4. Upload Files:

  • Click "Choose Files" to select files
  • Click "Upload" to send files to server (preserves extensions)
  • Files are uploaded to /upload endpoint

5. Send Commands:

  • discover - Auto-scan for server
  • GET / - Test basic HTTP request
  • POST /cgi-bin/script.py - Test CGI
  • DELETE /cgi-bin/script.py - Delete via CGI
  • DELETE /upload?file=filename.txt - Delete uploaded file
  • status - Get server status
  • Any valid HTTP request

6. Dynamic Port Support: The console automatically detects your WebServ configuration!
